# Devfolio — Portfolio Site + Client CRM

A React + Node.js project for a freelance web developer: a public portfolio
site, plus a private dashboard to manage clients, maintenance costs,
reminders, contracts, welcome notes, and thank-you cards. Clients get their
own login to see their own contract, maintenance plan, and reminders.

## Stack
- **Backend:** Node.js, Express, JWT auth, bcrypt — data stored in a simple
  JSON file (`backend/data/db.json`), so there's no database server to set up.
  Swap in Postgres/Mongo later if you outgrow it.
- **Frontend:** React (Vite), Tailwind CSS, React Router.

## 1. Backend setup
```bash
cd backend
cp .env.example .env      # then edit ADMIN_EMAIL / ADMIN_PASSWORD / JWT_SECRET
npm install
npm run seed               # creates data/db.json + your admin login
npm run dev                 # http://localhost:5000
```

## 2. Frontend setup
```bash
cd frontend
npm install
npm run dev                 # http://localhost:5173
```

## 3. Log in
Go to `http://localhost:5173/login` and use the admin email/password you set
in `.env`. From the dashboard you can:
- Add a **client** (this creates their portal login automatically)
- **Issue a contract**, mark it draft / sent / signed
- Set a **maintenance plan** (amount, billing cycle, next due date)
- Add **reminders** tied to a client, check them off as done
- Send a **welcome note**, **thank-you card**, or **issue update** — clients
  see these the next time they log in to their portal

## Making it yours
- Replace "Your Brand" in `frontend/src/components/Navbar.jsx` and
  `frontend/index.html` with your actual name/brand.
- Edit the hero copy and the `About` page (`frontend/src/pages/About.jsx`).
- Add real projects from **Dashboard → Portfolio**, or edit the seed data in
  `backend/utils/seed.js`.
- Colors and fonts live in `frontend/tailwind.config.js` — swap the palette
  in `theme.extend.colors` if you want a different look.

## Deploying
- Backend: any Node host (Render, Railway, Fly.io). Just make sure
  `data/db.json` is on a persistent disk, or migrate to a real database.
- Frontend: Vercel/Netlify. Set `VITE_API_URL` to your deployed backend URL.

## Project structure
```
backend/
  routes/        one file per resource (auth, clients, contracts, ...)
  middleware/    JWT auth + role checks
  utils/db.js    tiny JSON-file "database"
  data/db.json   generated by `npm run seed`
frontend/
  src/pages/           public site + login
  src/pages/admin/     your dashboard (CRM)
  src/pages/client/    what your clients see
  src/context/         auth state
  src/api/client.js    axios instance
```
